# 文章写作：文风样本与写法

> **先读 `analysis-playbook.md`。** 这份文件只记录样本里可观察到的写法，**不是硬配额**：标题不必短、不必转折或问句；主体不必 3—5 节；不要求人物/场景；比喻不是必选项；预测稿可以全篇零比喻。用户原话与 `analysis-playbook.md` 优先于本文；本文与它们冲突时，以它们为准。

这份文件给「文章写作」用。依据是三篇同类公众号样本（面向行业读者的观察号，样本的标题、署名与账号已脱敏），
下面写的是**从这些样本里能观察到的写法**，不是让你模仿它们的题材或句子。用户上传自己的语料后，语气档案（`voice/<档案>/profile.md`）优先于本文件。

## 一、样本的共同点（可迁移的部分）

1. **标题短、带转折或问句**。三篇都在 20 字以内，用对比、问句或「A｜B」的结构——没有一篇叫「关于……的分析」。
2. **开篇三句之内给东西**：要么一个带出处的硬数字，要么一个第二人称的场景，要么数字加一句设问。不铺垫行业背景，不写「随着……的发展」。
3. **小标题说人话**。名词短语、动宾短语、A：B 都行；三篇里只有一篇用了 1/2/3/4 编号，且编号后面仍是口语标题。
4. **一段一个意思，2—5 句**。允许一句话单独成段当一个停顿。
5. **数据一定带出处，且写在同一句里**：「伽马数据《女性向游戏调研报告》显示……」「根据中国音数协游戏工委数据……」「据宝可梦公司官网公布的数据……」「另有行业调研表明……」「（GameLook统计）」。
6. **事实段后面跟一句判断**，常常用破折号或「这才是/这足以说明/说到底」收住。
7. **术语第一次出现就解释**，用引号或括号就地解释。
8. **结语重新定性，不总结全文**；最后一两句短、可以抒情。
9. **署名与参考资料**：「文/署名」+「参考资料：伽马数据《…》、QuestMobile《…》、36氪、南方都市报、中国经营报等」。

## 二、文章写作的结构参考（按需取，不是模板，也不是配额）

下面的结构只说明这类样本常见的样子；用户给了结构、判断数或角度时，按用户的来。不要为凑节数硬加，也不要求每节同形。

```
标题（短、有转折 / 对比 / 问句，不超过 20 字）

开头（1—2 段）：
  一句带出处的数据，或一个第二人称的场景 + 一句定性。
  第三句就该出现本文要回答的那个问题。

主体（3—5 节，每节一个小标题）：
  每节：先给一个具体事实（案例、数字、时间、产品名）→ 再给一到两句判断 → 需要时补一个对比。
  节与节之间靠逻辑推进（从现象到机制到影响），不靠「首先其次最后」。
  一节里最多一个小标题下面再分「A：B」式的子块，不超过 3 个。

结语（1—3 段）：
  重新定性（不是总结），可以留一句短的、略带情绪的话。
  不写「综上所述」「总而言之」「未来可期」。

落款：文/署名
参考资料：报告名、媒体名、日期、链接（有就给）
```

## 三、句法与用词

- **短句为主，长短交替**。判断句短、事实句可以长；不要每句都 40 字。
- **动词开头**。「小游戏拓展了品类边界」比「品类边界的拓展是由小游戏实现的」好。
- **行业词可以用，但必须有具体所指**：破圈、续命、生意经、第二增长曲线——这些在样本里都跟着具体案例；「赋能、闭环、底层逻辑、生态位」在没有具体对象时不要写。
- **第二人称写场景，第一人称复数写共同经验**（「你盯着那个画面看了很久」「游戏给了我们快乐的起点」）。不要整篇「笔者认为」。
- **允许的标点**：破折号补充判断、问句推进、冒号引出清单、引号标术语。禁止用「```」装饰正文。
- **数字与中文之间留空格**（「2024 年」「536.92 万人次」），全篇统一即可。
- **不写「本文」「笔者」「我们团队」式的自我介绍**；也不写「以下是」「接下来我们来看」。

## 四、引用规范（重要，和文章写作绑定）

**正文不出现 `[1]`、`①`、`（数据来源：……）` 这类编号或括号。** 出处写在句子里：

| 场景 | 写法 |
| --- | --- |
| 引用报道 | 根据《XX》报道，……；据 XX 报道，…… |
| 引用统计 | 据 XX 统计，……；XX 数据显示，……；XX 披露，…… |
| 引用报告 | 伽马数据《XX 报告》显示，……；《XX 报告》显示，…… |
| 引用估算 | 据 XX 估算，……；XX 的测算显示，…… |
| 二手转述 | 据 XX 转述，……（不要写成一手） |
| 官方口径 | 据 XX 官网公布的数据，……；XX 在公告中披露，…… |

- 一句话里只用一个出处；同一段里不要每句都挂出处，隔句挂即可。
- 数字后面不需要再补编号；**一段里出现两个来源时，把第二个写成「另有……显示」。**
- 文末固定加：

```markdown
## 参考资料

1. 伽马数据《女性向游戏调研报告》，2026 年 10 月，https://…
2. QuestMobile《2025 手机游戏行业发展分析报告》，2026 年 9 月
3. 36氪《……》，2026 年 8 月 12 日，https://…
```

  没有链接的写「媒体名 + 文章/报告名 + 日期」；实在查不到日期的，写「日期不详」并说明。

## 五、AI 味的典型症状（交付前逐条对）

- [ ] 开头是「随着……的快速发展」「在……的背景下」「近年来，……」
- [ ] 每段第一句都是概括句，后面全是解释（概述 + 展开的机械循环）
- [ ] 三段式：现状—问题—建议，或者「首先/其次/最后」
- [ ] 排比三连（「不仅……而且……更……」）连着出现两次以上
- [ ] 空泛大词没有具体所指：赋能、闭环、生态、底层逻辑、抓手、护城河
- [ ] 「值得注意的是」「不难发现」「综上所述」「总而言之」「未来可期」
- [ ] 结尾喊口号（「让我们共同期待……」）或重复开头
- [ ] 正文里出现 `[1]`、①、或「（数据来源：……）」
- [ ] 每个数字都没有出处，或者出处全堆在文末、正文里一个都没有

有一条中，就回到对应段落改，不要只在结尾加一句缓冲。

## 六、对照两份真实输出：AI 味到底在哪

拿本插件此前生成的两篇初稿和上面三篇比，
**问题不在用词，在节奏和材料**。逐条对照，写之前先看这一节：

| 症状 | 生成稿里的样子 | 怎么改 |
| --- | --- | --- |
| 段段都是「判断句 + 证据」 | 每段第一句先下结论（「这个切法…」「切出去之后…」「真正被改写的是目标」），后面接依据，一节接一节 | 每节换一种推进：场景、一句对话、一组对比数字、一个反问、一句独立成段。连着三节同一种节奏就重排 |
| 同一个句式反复用 | 「不是 A，是 B」「真正 X 的是 Y」「不…而…」全篇出现七八次 | 这类对偶句全篇最多用两次，其余改成陈述句或直接给事实 |
| 法条串讲 | 第二条、第十条、第十四条、第十八条、第二十二条、第二十六条逐条读下来 | 只在关键处引一条（且只引半句），其余用「条款管的是什么事」来说；一份文件不要超过两处直接引用 |
| 整段搬文件原文 | 「利用人工智能技术，向中华人民共和国境内公众提供模拟自然人人格特征…」 | 引文最多一句、不超过 40 字；其余转述成你自己的话 |
| 没有人在里面 | 通篇是文件、数字、律所解读，没有一个玩家、一次对话、一个界面细节 | 至少给一个具体的人和时刻：一句玩家评论、一次深夜的试用、一个界面上看不见的提示、一句访谈原话 |
| 段落一样长 | 每段 3—5 句、120—180 字，视觉上像一块块砖 | 允许一句成段；关键判断后留白；长段之后接短句 |
| 小标题像公文 | 「一、定稿加上的『持续性』，把工具摘了出去」 | 小标题说人话：「三个字，把工具摘了出去」「线是活的」 |
| 数字和出处分离 | 正文里「[1]」，文末编号列表 | 出处写进句子：「据《证券日报》报道」「星野母公司招股书披露」；引文编号一律不要 |
| 比喻扎堆 | 段段结尾都要来一句金句比喻，甚至一段里叠两个 | 见下面「比喻：少、准、深」 |

判断自己写没写出来，用这个笨办法：**随机挑三段，看开头是不是都在下结论**。是，就重排。

### 比喻：少、准、深

这条来自作者对初稿的具体修改意见，比前面几条更容易犯：

1. **密度**：2000 字的分析文章，明确的比喻 / 类比全篇 2—3 处就够；**一段之内最多一处**；相邻两段不要都收在比喻上。
2. **不要用比喻重复上一句**：找不出新信息就别打比方。上一句已经说了「被要求自己打断自己」，下一句再补「等于一上线就要写检查」，只是换了个说法再说一遍，还多了一个比喻。
3. **要打就往深处打**：比喻的价值是点出机制，不是添情绪。「一上线就要写检查」说的是流程；「无异于一把高悬着的达摩克利斯之剑」说的是**随时可能落下、且不由自己控制**——后者才配得上那个位置。
4. **一个比喻体系用到底**：不要一篇里又是武侠又是物理学又是考试，混着用会显得在凑句子。
5. 能用事实说清的地方不用比喻；比喻留给那些「抽象到没有画面」的判断。

对照：

```
差（连续两段都用比喻收尾，第二句还是重复）：
  ……一个靠"秒回"和"离不开"活着的产品，被要求在用户最投入的时候自己打断自己。
  真正让人紧张的是同一句里的"责令停止提供相关服务"——对刚上线的陪伴产品，等于一上线就要写检查。

好（只留一处，且这一处说得更深）：
  ……一个靠"秒回"和"离不开"活着的产品，被要求在用户最投入的时候自己打断自己。
  真正让人紧张的是同一句里的"责令停止提供相关服务"。对刚上线的陪伴产品而言，
  这无异于一把高悬着的达摩克利斯之剑。
```

自查：通读一遍，把每处比喻圈出来。**如果每节都有，删到两三处；如果两处说的是同一个意思，删掉一处。**

## 七、和「深度研究型文章」的关系

深度研究型沿用本文件的**语感**（短句、判断句、一段一个意思、行内归属、参考资料），
但它的**语言严度、排版精度、引用方式、禁止推论与展望**另有一份专门规范：[`deep-research.md`](deep-research.md)。

两条分工记清楚，别混：

- 写**分析型**：重点在本文件（怎么起标题、怎么开头、一段几句、比喻放几处）。
- 写**深度研究型**：两份都读——本文件管「怎么写得像人」，`deep-research.md` 管「证据够不够、结构立不立得住、语言够不够严、该做哪些校验」。
- 三处一眼看得出的差别：开头（分析型场景/硬数据/设问 vs 摘要）；比喻（2—3 处 vs 一处也不要有）；结尾（重新定性 vs 只写材料支持的结论，不推测不展望）。

## 八、素材说明

样本来自作者已公开发表的三篇公众号文章。提取时只保留可迁移的写法（标题、开头、段落节奏、引用方式），不保留原文句子、题材与署名；本文件随插件公开发行，因此不再列出文章标题与账号。
