# wechat-analysis · 文章写作的写法与审校

`references/analysis-playbook.md` 是文章写作的**唯一规则正文**：任务拆解、预测/机制/争议分流、提纲检查点、证据口径、交付流程都在那里。本目录只补两块“落到句子上”的写法，接在 playbook 对应的阶段：

| 阶段 | 读什么 | 管什么 |
|---|---|---|
| 写正文、大幅重写 | `drafting.md` | 真实材料开稿；让对象和动作先出现；每段增加一项读者需要的信息；例子只支持它实际说明的范围 |
| 拿到草稿、只润色、交稿前 | `editing.md` | 先改判断再改句子；只改有具体问题的地方；改完对原稿和来源保真回读 |

## 调用点

- `analysis-playbook.md` 第五节（结构与中文）与第六节（交稿前的两轮修订）
- `lib/skills.js` 的插件入口说明、`lib/jobs.js` 的分析型后台约束、`gallery/prompts.js` 的分析型任务说明

## 来源与取舍

- `gzh-human-writing` 1.0.0（MIT，见 `LICENSE-gzh-human-writing.txt`）提供正文写法：以真实材料开稿、明确作者凭什么下判断、优先写做事的人和动作、每段增加一项新信息。**放弃**了固定材料件数、固定短稿字数和整篇标点禁令——按论证需要选择材料和篇幅。
- `deai-promax-wechat` 1.0.0 提供审稿方法：定位模糊归因、口号式收尾、段落同构、刻意换词，以及词句层面的误改。**省略**了原脚本的评分机制、分数目标、造停顿、强制删主语和改动引语的写法——验收标准是证据、表意和阅读，不是分数。
- 两包的示例正文没有随包分发；`drafting.md` 末节提到的女性向稿与 IP 稿只作为“选材与解释过程”的示范，不当作配额。
