# 字体说明

本技能**不捆绑字体文件**，导出器只在 `.docx` 中写入字体名，由 Word/WPS 在本机解析。

## 需要的字体

| 用途 | 字体 | 字号 |
| --- | --- | --- |
| 公文标题、版头 | 方正小标宋简体 | 2 号（22pt） |
| 一级标题 | 黑体 | 3 号（16pt） |
| 二级标题 | 楷体_GB2312 | 3 号（16pt） |
| 正文 | 仿宋_GB2312 | 3 号（16pt） |

## 本机没有这些字体时

按优先级选择一种：

1. **使用系统已装字体**：在 Word 中把字体名替换为“宋体”“黑体”“楷体”“仿宋”。版式不变，字形略有差异。
2. **使用开源替代**：导出时加 `--font-preset noto-cjk`（Noto Serif SC / Noto Sans SC / FandolFang）或 `--font-preset fandol`。需本机已安装对应字体。
3. **自行安装**：从本单位正版字体包或系统字体目录获取 `仿宋_GB2312`、`楷体_GB2312`、`黑体`，双击安装；`方正小标宋简体` 为商用字体，使用和分发前确认授权。

## 授权提示

- `方正小标宋简体` 属商用字体，未经授权不得随包分发或用于商业发布。
- `仿宋_GB2312`、`楷体_GB2312` 的授权边界因来源而异，使用前自行确认。
- 开源替代（Noto、Fandol）采用 SIL Open Font License 等开源许可，可自由分发。

## 为什么不在包里放字体

字体二进制体积大（约 16MB），且商用字体再分发有授权风险。技能只负责版式参数，字体由使用单位按自身授权环境准备，更安全也更通用。
