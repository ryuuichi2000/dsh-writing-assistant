# 工作总结（summary）

- 类别：常见正式材料
- 别名：工作总结、总结、总结材料
- 适用：用于阶段性复盘、年度总结、专项工作总结。
- 字体/版式方案：`internal-readable` / `internal-readable`

## 起草前确认

- 总结的时间范围、工作范围和总体目标。
- 主要做法、工作成效（含数据口径）。
- 存在问题和下一步打算。

## 撰写思路

- 标题用“[单位][时间][事项]工作总结”。
- 正文按“基本情况—主要做法—工作成效—存在问题—下一步打算”展开。
- 做法和成效要对应，一条做法对应一条结果。

## 写作规则

- 总结要写“做了什么、怎么做的、效果如何、还有什么问题”，不写成流水账。
- 成效用事实和数据支撑，数据注明口径和时点；未核实的数据留占位。
- 存在问题要具体，不写“还存在一些不足”这类空话。
- 下一步打算与问题对应，写清措施、责任和时限。

## 常见误写

- 罗列工作过程，没有提炼做法和成效。
- 成绩夸大、问题虚化。

## 模板

```markdown
# [单位名称][时间范围][事项名称]工作总结

## 正文

一、基本情况

[写明工作背景、时间范围、总体目标和总体情况。]

二、主要做法

（一）[做法一]

[写明具体做法、推进方式和责任落实。]

（二）[做法二]

[写明具体做法。]

三、工作成效

[写明主要成果、数据和典型经验，数据注明口径和时点。]

四、存在问题

[写明短板不足、风险隐患或制约因素。]

五、下一步打算

[写明下一阶段工作安排、改进措施、责任和时限。]

## 落款

[单位名称]

[日期]
```

> 内部口头总结可不加落款；正式报送的总结保留单位和日期。
