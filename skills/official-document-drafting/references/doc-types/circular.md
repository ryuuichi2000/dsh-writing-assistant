# 通报（circular）

- 类别：法定公文
- 别名：通报
- 适用：用于表彰先进、批评错误或传达重要情况。
- 字体/版式方案：`official-standard` / `official-standard`

## 起草前确认

- 通报类型（表彰/批评/情况），以及事件经过、对象和结果。
- 评价依据、经验教训或原因分析。
- 整改、追责、推广或防范要求。

## 撰写思路

- 标题用“关于[事项]的通报”。
- 正文按“基本情况—评价分析—工作要求”展开。
- 表彰类突出事迹和可推广做法；批评类写清事实、性质和教训；情况类突出态势和要求。

## 写作规则

- 通报用事实说话，表彰和批评都要有具体事实和依据，不夸大、不上纲。
- 批评类通报要写明错误事实、性质、处理决定和整改要求；涉及个人姓名的，按组织决定口径写。
- 同一事项的表彰和批评不混写；确有必要的，分节写清。
- 工作要求要可执行，写明向谁学、改什么、何时报。

## 常见误写

- 把通报写成通告，面向社会发布强制性事项。
- 只有评价没有事实，或只有事实没有要求。

## 模板

```markdown
# 关于[事项名称]的通报

## 主送单位

[主送单位]：

## 正文

近期，[事件或工作情况概述]。为[目的]，现将有关情况通报如下：

一、基本情况

[写明事件经过、对象范围、主要结果或典型事迹。]

二、评价分析

[写明性质影响、经验做法、原因分析或警示意义。]

三、工作要求

[写明学习推广、整改追责、防范措施和报送要求。]

## 落款

[发文单位]

[日期]
```
