# 讲话稿（speech）

- 类别：常见正式材料
- 别名：讲话稿、发言稿
- 适用：用于领导讲话、会议发言、动员部署和总结点评。
- 字体/版式方案：`speech-readable` / `speech-readable`

## 起草前确认

- 讲话场合、会议名称、讲话人身份和听众对象。
- 讲话主题、重点任务和要求。
- 需要引用的政策、数据和典型事例。

## 撰写思路

- 标题用“在[会议名称]上的讲话”。
- 称谓顶格写“各位领导、同志们：”。
- 正文按“开场说明—形势判断—重点任务—工作要求—结束语”展开；以书面语为主，句子短、可朗读，允许少量口语色彩。

## 写作规则

- 讲话稿是口语文本，句子不宜过长，多用短句和排比，便于朗读。
- 称谓、称呼要符合会场实际，不虚构参会范围和领导姓名。
- 重点任务分点讲，每点先讲“做什么”，再讲“为什么”“怎么做”。
- 结束语收束有力，不喊空洞口号；引用政策、数据要有依据。

## 常见误写

- 把讲话稿写成书面报告，长句、层次过多，不适合讲。
- 通篇口号，没有具体任务和要求。

## 模板

```markdown
# 在[会议名称]上的讲话

## 称谓

各位领导、同志们：

## 正文

[开场：交代会议背景、讲话目的和总体评价。]

一、[形势判断/提高认识]

[分析当前形势、任务要求或存在问题。]

二、[重点任务]

（一）[任务一]

[讲清做什么、为什么、怎么做。]

（二）[任务二]

[讲清做什么、为什么、怎么做。]

三、[工作要求]

[讲清组织领导、责任落实、纪律作风等要求。]

[结束语：总结收束、发出号召。]
```
