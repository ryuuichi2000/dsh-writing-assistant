# 情况专报（special-report）

- 类别：常见正式材料
- 别名：情况专报、信息专报、舆情专报、专报
- 适用：用于向领导或上级报送专题信息、风险情况和舆情态势。
- 字体/版式方案：`internal-readable` / `internal-readable`

## 起草前确认

- 事件或专题的基本情况、时间地点和涉及主体。
- 已核实的最新进展和已采取措施。
- 风险点、趋势判断和工作建议。

## 撰写思路

- 标题用“关于[事项]的情况专报”或“[事项]情况专报”。
- 正文按“事项概况—最新进展—风险研判—工作建议”展开，先事实后判断。
- 风险研判和建议是专报的重点，要写足、写具体。

## 写作规则

- 专报突出“专”和“快”，一事一报，篇幅服从内容。
- 事实与研判分开写，判断要有依据，不把推测写成事实。
- 风险研判写清风险点、影响范围、发展趋势和触发条件。
- 工作建议写清谁来做、做什么、何时做；需要上级协调的单列。

## 常见误写

- 把专报写成情况通报或新闻稿，研判和建议缺失。
- 事实与判断混写，读者无法分辨哪些已核实。

## 模板

```markdown
# 关于[事项名称]的情况专报

## 报送对象

[领导同志]：

## 正文

[导语：交代事件起因、时间地点、涉及主体和当前总体态势。]

一、事项概况

[写明事件背景、涉及主体、时间地点和当前基本态势。]

二、最新进展

[写明已核实的最新动态、已采取措施和当前结果。]

三、风险研判

[写明主要风险点、影响范围、趋势判断和触发条件，与事实分开表述。]

四、工作建议

[写明建议采取的措施、责任主体、时限和需要上级协调的事项。]

## 落款

[报送单位]

[日期]
```

> 落款按本单位专报格式取舍：有的专报只在文末署报送单位和日期，有的把报送信息放在版记；不需要时整段删除即可。
