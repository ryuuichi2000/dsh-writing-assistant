# 决议（resolution）

> **留档文件，未在当前模板列表里。** 决议已按用户要求从 `assets/registry.toml` 和「模板起草」的勾选列表移除，
> 自动机检 / 导出（`--doc-type 决议`）也不再识别它。需要恢复时，把本文件对应的注册表条目加回 `registry.toml` 即可。

- 类别：法定公文
- 别名：决议
- 适用：会议讨论通过的重要决策事项。
- 字体/版式方案：`official-standard` / `official-standard`

## 起草前确认

- 会议全称、召开时间、届次，以及决议事项经表决通过的情况。
- 提交会议审议的文件或议题名称。

## 撰写思路

- 标题用“[会议名称]关于[事项]的决议”，在标题下括注通过日期和会议名称。
- 正文先交代会议召开和审议情况，再写会议形成的结论和落实要求。
- 决议事项较多的，用“一、二、三、”逐项写结论，不写讨论过程。

## 写作规则

- 决议必须经会议讨论表决通过，以会议名义发布；未经表决的不写“决议通过”。
- 只写会议最终形成的结论，不写发言、分歧和过程性细节。
- 涉及表决结果的，写明“会议表决通过”“一致同意”等实际口径，不推测票数。
- 决议事项要能执行，原则上写明责任主体、时限或后续安排。

## 常见误写

- 把决议写成会议纪要：纪要是议事记录，决议是会议表决形成的决定。
- 未经会议表决却写“会议通过”“一致同意”。

## 模板

```markdown
# [会议名称]关于[事项名称]的决议

## 题注

（[YYYY年M月D日][会议名称]通过）

## 正文

[会议名称]于[日期]召开。会议听取和审议了[事项]，认为[总体评价]。

会议决定，[决议事项的总体表述]。

一、[决议事项一]

[写明会议表决通过的具体内容、执行主体和时限。]

二、[决议事项二]

[写明具体内容、执行主体和时限。]

会议号召，[落实要求或号召事项]。
```
